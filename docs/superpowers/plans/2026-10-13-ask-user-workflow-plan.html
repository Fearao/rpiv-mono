Ask User Workflow Implementation Plan

For agentic workers: execute inline using executing-plans and TDD. The user explicitly approved implementation; no delegation.

Goal: Retain upstream questionnaire UI with eight questions, opt-in xnotify and stop-on-cancel semantics.

Architecture: Small policy and event adapters, no UI rewrite. Pure response formatting distinguishes cancellation, errors and unanswered submissions. Sequential tool execution plus cancellation hook stops mixed batches.

Tech Stack: TypeScript, TypeBox, Vitest, pi 1.1.0.
