Ask User 薄 fork

用户已在会话批准范围并授权公开 GitHub fork 与实施。基线：juicesharp/rpiv-mono，2d88b79c08ce19ffeecbe85d5ee1071046b708c0，问卷包 2.13.8。

范围

  • 只暴露 ask_user_question，保留上游 UI、草稿、多选、预览、备注、折叠、RPC 与无 UI 隐藏。
  • 每次 1–8 题，每题 2–4 个选项；默认模型指导推荐 2–4 题。
  • 独立 xnotify 适配器通过 rpiv:ask-user:prompt 事件非阻塞发送一次摘要；默认关闭，接收者仅来自本地 config.json。无 shell 字符串拼接；5 秒超时；异常与非零退出只报告固定诊断、不阻塞问卷、不输出接收者/题目。
  • 显式取消返回 terminate:true，并用 tool_result 中 ctx.abort() 停止混合工具批次的后续执行；工具采用 sequential 模式。已执行的其他操作不回滚，指导模型不要与其他工具合批。
  • 验证失败、无 UI、加载失败不能触发取消停止。空白提交是未回答，不是取消。
  • 部分提交保留 unanswered 索引与明确文案，不接受默认推荐；仍有阻塞决策时必须澄清，不自动继续依赖该决策的操作。

边界

不安装整套 rpiv，不添加 i18n 依赖，不保留旧答案格式，不注册旧工具别名，不修改全局 pi 配置或其他仓库文档。兼容已有原工具的指导在 fork 内使用新工具名说明。

交付

公开 fork 中独立功能分支；根目录 pi manifest 只发现问卷包以便 Git 安装，不误加载整个 monorepo；根依赖以 workspace 链接保证 rpiv-config 可用。保留上游 MIT 许可与来源，记录升级流程与补丁。

测试

先记录上游问卷包基线，测试先红后绿；覆盖 8/9 题 schema 与运行校验、实际组件 8 题提交、通知配置/失败/非阻塞/集成、TUI/RPC 取消、错误不停止、空白与部分提交、实际 pi SDK agent loop 的混合批次停止。跑问卷包全量回归、类型与 lint；使用隔离配置做 Git 安装和 TTY smoke，不改真实 pi 安装。不宣称未做的人工视觉验收。
